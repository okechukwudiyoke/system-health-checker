# Linux System Health Checker

A Python-based Linux system monitoring tool built as part of my DevOps learning roadmap.

## Features

- Displays hostname
- Identifies operating system
- Displays Linux kernel version
- Reports disk capacity and usage
- Reports available disk space
- Calculates system uptime

## Technologies

- Python 3.12
- Linux
- Ubuntu 24.04 LTS
- Git
